
# UniManager

Applicazione in Java per la gestione degli esami di un ateneo:
 studenti, corsi, appelli, iscrizioni, voti e medie.

Progetto del corso di Programmazione ad Oggetti, Università di Bologna.
#   Requisiti
 JDK  o successivo
 Gradle

     ## Comandi
     "gradle run" avvia l'applicazione
  "gradle test" esegue i test

# Struttura
 "src/main/java": codice (package "model", "controller", "view")
 "src/test/java": test JUnit
"report": relazione ("relazione.pdf" e sorgente LaTeX)
